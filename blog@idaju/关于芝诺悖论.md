二分法问题和阿喀琉斯问题已经被微积分的思想和概念解决。

箭头问题在于语言概念没有厘清，运动的箭头在每一时刻都占据一个位置，但是你不能说它在每一时刻都是静止的（所以运动的箭头是不动的），仅通过一个时刻是无法判断一个物体是否运动的，就像你只通过一张照片是无法判断照片中的物体是否运动的，你必须通过一个视频才能判断，因为照片与视频的一个区别就是，照片只呈现一个时间点，而视频呈现多个时间点，所以要判断一个物体是否运动，至少需要两个不同的时间点。静止和运动这两个概念建立的前提是时间的流逝和变动。

赛跑场悖论恰恰论证了时间的无限可分，不存在最小的时间间隔。

A A A A         （静止）
B B B B  →     （向右）
    C C C C  ← （向左）

如上图所示，设想 A 表示赛跑场上 4 个不动的观众，B 表示以速度 V 向右奔跑的 4 个运动员，C 表示以速度 V 向左奔跑的 4 个运动员，假设在时间间隔 T 内，B 和 C 正好经过一个 A，那么在时间间隔 T 内，B 经过 2 个 C，但是在现实中，我们知道，B 必然可以只经过一个 C，如果经过两个 C 需要时间 T，那么经过一个 C 就需要 T/2 的时间。

我们知道现实中这个 T 一般不是最小的时间间隔，假设现实中最小的时间间隔为 t，我们把前述的观众和运动员换成极微小的粒子 a、b、c，给它们安排适当的间距和速度 v，使其在最小的时间间隔内，b 和 c 正好经过一个 a，与上面相同的论证过程同样成立。如果存在最小的时间间隔 t ，那么就必然存在 t/2 的时间间隔，这与假设相矛盾。也就是说时间必然是无限可分。
